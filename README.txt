JAYA MAKMUR — MULTI-PAGE STATIC WEBSITE
========================================

Cara menggunakan:
1. Ekstrak seluruh folder.
2. Buka index.html di browser.
3. Untuk hosting/GitHub Pages, upload seluruh isi folder dengan struktur yang sama.

Halaman:
- index.html
- tentang.html
- layanan.html
- cold-room.html
- air-blast-freezer.html
- insulation-panel.html
- mesin-pendingin.html
- kontak.html

Fitur:
- Website statik HTML/CSS/JS (tanpa framework, tanpa build process).
- Responsive desktop/mobile.
- Tombol WhatsApp mengambang pada semua halaman.
- Form konsultasi di kontak.html yang membuka WhatsApp dengan pesan terisi otomatis.
- Multi-page, semua link menggunakan path relatif.
